# 7Stars Builder — план и статус

Клиентский мод для Minecraft 1.19.2 (Forge). Показывает призрак постройки в прицеле. После подтверждения отправляет на сервер команды `/fill` и `/setblock`, для этого нужны права OP.

## Технологии

- Minecraft 1.19.2, Forge 43.x, Java 17
- Gradle 7.6.4 (лежит в `.tools/gradle-7.6.4`, в `.gitignore`)
- mappings: official
- mod id: `sevenstars_builder`
- Формат постройки: текстовый скрипт (`name`, `fill`, `set`, `def`, `let`, `loop`), см. README

## Структура

- `mod/` — проект Forge: `src/main/java`, `src/main/resources`, `build.gradle`
- `.tools/` — Gradle для сборки (не в git)
- `builds/` — готовые постройки `.txt`, не относятся к моду
- `build.txt` — команда сборки
- `README.md`, `PLAN.md`

## Этапы

1. **Каркас.** Gradle, Forge, мод грузится, jar собирается. *Сделано в коде. Сборка не проходила из-за сертификата Forge, не проверено.*
2. **Загрузчик.** Чтение `.txt` из `config/sevenstars_builds/` при запуске, `/sb list`, `/sb use`. *Сделано в коде, не проверено.*
3. **Призрак.** Полупрозрачные блоки в точке прицела через `RenderLevelStageEvent`. *Сделано в коде (`GhostRenderer`), не проверено.*
4. **Управление.** Выбор постройки `]`, поворот R, сдвиг стрелками, PgUp/PgDn, фиксация G, построить Enter, остановить Backspace. Клавиши призрака активны только при включённом призраке. *Сделано в коде, не проверено.*
5. **Установка.** Очередь команд `/fill` и `/setblock`, по одной команде в тик, прогресс в чате. *Сделано в коде, не проверено.*
6. **Откат.** Запоминать область перед постройкой и откатывать через `/clone` или обратную перестановку. *Не сделано.*
7. **Экспорт.** Сохранение зоны мира в скрипт: `/sb pos1`, `/sb pos2`, `/sb export`. *Сделано в коде (`WorldExporter`), не проверено.*
8. **Проверка.** Сборка, запуск в игре, тест на сервере, правки, релиз jar. *Не сделано.*

## Открытые вопросы

- **Заход на сервер без мода.** В `mods.toml` нет настройки `displayTest`. Пока неизвестно, пустит ли сервер игроков без мода. Нужно проверить и при необходимости добавить `IGNORESERVERONLY`.
- **Откат.** Без отката ошибочную постройку придётся убирать вручную или через `/fill` с нужным блоком.
- **Большие постройки.** Мод отправляет одну команду в тик, для больших построек это несколько минут. Сервер может ограничивать частоту команд, тогда понадобится пауза между пачками.

## Риски

- Лимит `/fill` — 32768 блоков. Большие области режутся на части (это уже сделано в `BuildDefinition` и генераторах).
- Лимит скрипта — 20000 операций.
- Сервер может не разрешать команды `/fill` и `/setblock` обычным игрокам.
