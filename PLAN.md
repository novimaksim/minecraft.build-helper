# 7stars Builder — план (Forge 1.19.2, клиентский мод)

## Цель
Клиентский мод: показывает «призрак» постройки, после подтверждения ставит её на сервере командами /fill и /setblock (нужен OP). Постройки генерирую я скриптами.

## Технологии
- Minecraft 1.19.2, Forge 43.x, Java 17, Gradle (wrapper), mappings: official
- mod id: sevenstars_builder
- Клиентский режим: displayTest = IGNORESERVERONLY, чтобы заходить на сервер без мода

## Структура репозитория
- mod/ — проект Forge (src/main/java, resources, build.gradle)
- builds/ — готовые постройки (.json)
- scripts/ — Python-генераторы построек (castle.py, tower.py ...)
- .tools/ — локальный JDK и кэш Gradle (в .gitignore)
- PLAN.md

## Формат постройки (JSON)
{
  "name": "tower",
  "size": [x, y, z],
  "palette": {"a": "minecraft:stone_bricks", "b": "minecraft:oak_planks[...]"},
  "ops": [
    {"op": "fill", "from": [0,0,0], "to": [4,0,4], "block": "a"},
    {"op": "set",  "pos": [2,1,2], "block": "b"}
  ]
}
Координаты относительные. Операции fill дают мало команд, поэтому установка быстрая.

## Этапы
1. Каркас: Gradle, Forge MDK, мод грузится, клиентский режим, сборка jar.
2. Загрузчик: чтение builds/*.json из config/sevenstars_builds/, команда /sbuild list.
3. Превью-призрак: RenderLevelStageEvent, полупрозрачные блоки в точке прицела.
4. Управление: клавиши — выбор постройки, поворот (R), сдвиг, подтвердить (Enter), отмена (Esc).
5. Установка: очередь команд /fill и /setblock, пауза между пачками (антиспам), прогресс в чате.
6. Отмена: перед стройкой запоминаем область, откат через /clone или перестановку (опция).
7. Скрипты построек: Python-генераторы, я пишу по запросу («сделай замок»).
8. Тесты на сервере, правки, релиз jar.

## Риски
- Сервер может ограничивать команды/скорость — тогда настраиваем размер пачки и задержку.
- Лимит /fill — 32768 блоков за команду, большие области режем на части.
- Нужен JDK 17 (пользователь ставит сам или я кладу в .tools/).
